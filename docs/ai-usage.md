# AI Tool Usage

AI coding assistance was used during development for implementation support, debugging, code review, test generation, documentation and reasoning about architecture.

## Tools Used

- ChatGPT

## How AI Was Used

AI assistance was used to:

- Discuss and refine the system architecture
- Implement and debug Go components
- Reason about policy and decision-engine behavior
- Develop and improve tests
- Debug PostgreSQL and API behavior
- Improve the REST confirmation flow
- Review implementation details
- Generate and refine project documentation and README content

All generated suggestions were reviewed, integrated and tested locally.

The final implementation was validated through automated Go tests and end-to-end API/database tests.
